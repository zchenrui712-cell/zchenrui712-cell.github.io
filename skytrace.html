03 / Hackathon

SkyTrace Live

A team concept and web prototype for starting an aircraft search with a camera or photo.

2026 Australia HackathonComputer vision · Flight data

01 / Question

What the project asks

Someone looking up at a passing aircraft may know where they are pointing but have no flight number to search. The project explores how an aircraft search can start from that observation.

02 / Approach

How the team approached it

Live mode ranks nearby ADS-B flight candidates using the device’s position and orientation. Photo mode compares exact and perceptual image fingerprints against a reference catalogue. The prepared source package includes one attributed Airbus reference photo.

03 / Contribution

My role

I helped shape the concept, contributed code, and debugged the prototype with my teammates.

04 / Interpretation

How to read the work

The live workflow depends on sensor quality and flight-data coverage. Photo mode can leave unfamiliar images unidentified. The included tests cover matching the known sample and rejecting an unrelated fingerprint.

Try the demo

Inspect a Boeing 787-9 sample flight or try matching an aircraft photo against the reference catalogue. The hosted demo uses sample flight data. Photo comparison runs in your browser.
